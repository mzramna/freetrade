## Store categories and metadata

- **Modrinth categories:** `economy`, `game-mechanics`, `utility`
- **CurseForge categories:** `Game Mechanics`, `Server Utility`, `Miscellaneous` (check the list shown in the CurseForge upload form, since category names can change)
- **Environment:** client and server, both **required**. Install on the server and on every client.
- **Optional dependencies:** JEI or EMI (client, for drag-and-drop and tooltips), Lightman's Currency (client and server, for coins and the bank option), PostgreSQL (server, optional database).
- **Suggested tags:** `economy`, `trade`, `villager`, `market`, `supply and demand`, `shop`, `neoforge`, `server`, `modpack`, `postgresql`, `sqlite`, `lightmans currency`, `jei`, `emi`
- **Suggested tags (pt-BR):** `economia`, `comércio`, `aldeão`, `mercado`, `oferta e demanda`, `loja`, `neoforge`, `servidor`, `modpack`, `postgresql`, `sqlite`
